# 포트폴리오 영상·사이트 카드 원고

사용 원칙: 아래 원고는 실제 화면에서 확인한 장면만 사용한다. 다른 장면으로 바뀌거나 오류가 나면, 해당 문장은 말하지 말고 캡처·로그를 남긴 뒤 수정한다.

## Phase 2 — 45~60초 시연 영상

### A. Evidence-Gated Work Agent (목표 55초)

| 시간 | 화면/행동 | 보여 줄 사실 | 내레이션 예시 |

| 0~6초 | 라이브 또는 로컬 첫 화면 | 프로젝트의 목적 | “근거가 충분할 때만 계획을 만들고, 사람 승인 전에는 실행하지 않는 Agent 데모입니다.” |
| 6~16초 | 충분 근거 시나리오 입력 | 계획 생성과 `PENDING_APPROVAL` | “공개 규정 근거가 통과하면 제한된 계획이 승인 대기 상태로 생성됩니다.” |

| 48~55초 | 부족/상충 근거 사례 | 차단 우선 설계 | “근거가 부족하거나 상충하면 계획·승인·실행을 모두 만들지 않습니다.” |

촬영 전 체크:

- [ ] 데모 데이터 초기화 여부를 확인했다.
- [ ] Render 유휴 기동 지연을 피하려고 미리 접속했다.
- [ ] 실제 외부 업무 실행이 아닌 mock임을 영상 설명/자막에 넣었다.
- [ ] 409, 승인, audit 화면을 하나의 연속 녹화에서 확인했다.

- [ ] 대시보드가 열리지 않으면 README 실행 재현 장면으로 바꾼다.

### 영상 배치 규칙

- GitHub에는 45~60초 MP4 전체를 직접 커밋하지 않는다. Release asset, YouTube 비공개/일부공개, 또는 포트폴리오 호스팅 링크를 사용한다.
- README에는 영상 링크와 촬영 날짜만 넣고, “검증 완료”는 실제로 장면을 확인한 항목으로 제한한다.
- 자막 첫 줄에 `합성 데이터`·`mock 실행` 등 오해를 막는 고지를 넣는다.

## Phase 3 — 포트폴리오 사이트 카드 원고

### Evidence-Gated Work Agent

**한 줄 소개**  
근거가 충분할 때만 계획을 생성하고, 사람 승인 전 실행을 서버에서 차단하며 감사 이력을 남기는 결정론적 Agent 워크플로 프로토타입.

**검증 근거**  
공개 규정 요약 10건·합성 fixture 4건·고정 평가 14/14·pytest 156 passed. 외부 API와 실제 업무 실행은 사용하지 않음.

**한계**  
공개 데모의 SQLite는 재시작 시 초기화될 수 있으며, 실제 조달·메일·결재 자동화를 실행하지 않음.

### Smart Manufacturing ML Portfolio

**한 줄 소개**  
합성 제조 센서 데이터에서 데이터 검증, 시간 순서 분할, 예측·이상 탐지, 드리프트 관측과 실행 이력을 연결한 재현형 ML 파이프라인.

**검증 근거**  
Docker·SQLite·Flask 대시보드·테스트 기반으로 실행 경로를 구성하고, 최신 지표는 저장소의 증빙 문서에서 확인 가능.

**한계**  
합성 데이터 기반 결과로 실제 생산 라인 성능이나 현장 적용 효과를 주장하지 않음.

### Steel Surface Defect Classification

**한 줄 소개**  
공개 NEU-CLS 이미지에서 중복 제거와 누수 방지 분할, ResNet18 분류, 입력 품질 진단과 신뢰도 평가를 재현한 컴퓨터 비전 실험.

**검증 근거**  
SHA-256 중복 제거, stratified 70/15/15 분할, 고정 test split 기반 지표와 테스트를 README에 공개.

**한계**  
단일 공개 데이터셋·고정 split 실험이며 실제 현장 일반화, 객체 탐지, 세그멘테이션을 주장하지 않음.

### Multiplay Fishing Game — 보조 카드

**카드 분류**  
`C# · Unity · 팀 프로젝트`

**한 줄 소개**  
Unity 6와 Mirror 기반 팀 멀티플레이 낚시 게임에서 Excel 데이터 관리, 멀티플레이 흐름 통합, 캐릭터 이동, 도감·상점 기능 구현을 담당.

**표기 주의**  
팀 결과 전체를 개인 작업으로 표현하지 않는다. Host/Client 2인 접속, 낚시 보상, 도감 반영, 상점 판매는 영상과 테스트로 실제 확인된 범위만 상태를 적는다.
