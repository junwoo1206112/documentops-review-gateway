# Phase 13 스크린리더 실사용 검증 프로토콜

자동 DOM 검사와 화면 캡처는 이 검증을 대체하지 않는다. 사람 검토자가 NVDA, Narrator 또는 VoiceOver 중
하나와 브라우저를 선택해 키보드만으로 아래 흐름을 한 번 완주한다.

1. 홈 화면에서 첫 Tab으로 본문 건너뛰기를 사용하고 업로드 입력의 안내를 청취한다.
2. `DEMO-0002.txt`를 올려 HOLD 상태·`LINE_TOTAL_MISMATCH`·근거 span 안내를 청취한다.
3. `DEMO-0001.txt`를 올리고 별칭·사유를 입력해 승인한 뒤 상태와 감사 이력을 청취한다.
4. Phase 14-I를 검토할 경우 품목 수정 선택지, 원문 재인용, 행 anchor 안내와 오류 메시지도 확인한다.

기록 양식은 `docs/reviews/phase-13.md`에 다음을 남긴다: 사용한 OS/스크린리더/브라우저, 각 단계의
성공·실패, 실제로 들은 문제 문구, 차단점, 수정·재검증 결과. 완료 선언은 사람이 이 기록을 채운 뒤에만 한다.
