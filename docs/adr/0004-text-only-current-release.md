# ADR 0004 — 현재 릴리스는 텍스트 전용으로 유지

- 상태: 승인됨
- 결정일: 2026-11-27
- 결정자: 프로젝트 오너 위임 + 전문가 A/B/C 교차 검증

## 맥락

P-001은 스캔 이미지/PDF OCR 확장을 후보로 남겼다. 하지만 현재 공개 데모는 합성 `.txt`
두 레이아웃을 원문 근거·규칙 검증·`HOLD`·사람 승인·append-only 감사로 처리하며, 실제 스캔
문서 수요·입력 형식·OCR 엔진/라이선스·보존 정책은 제공되지 않았다.

## 결정

이번 릴리스는 **텍스트 전용을 유지하고 OCR을 채택하지 않는다.** 따라서 이미지/PDF 업로드,
`source_kind=scan`, OCR provider, OCR fixture, OCR 바이너리·외부 API 및 원본 이미지 보관은
추가하지 않는다.

실제 스캔 문서 요구가 생기면 P-001을 새 Gate로 재개한다. 그때에만 입력 형식, 엔진/라이선스,
실행 위치·외부 전송, 최소 품질 임계값, evidence/좌표 형식, 보존·삭제 정책을 확정하고 Phase 16을
독립적으로 수행한다.

## A/B/C 교차 검증

| 관점 | 판단 | 반영 |
|---|---|---|
| A. 제품 | 프로젝트의 핵심 가치는 OCR 주장보다 근거 기반 검증과 사람 승인이다. 실제 스캔 수요 없는 확장은 사용자 가치를 검증하지 못한다. | 텍스트 전용 경계를 현 릴리스의 명시적 기능 범위로 고정한다. |
| B. 보안·운영 | OCR은 이미지/PDF 원본, 엔진 패치·라이선스, 외부 전송·보존 책임을 새로 만든다. | 원본 수집·외부 OCR·바이너리 의존을 추가하지 않는다. |
| C. QA·재현성 | confidence·좌표의 의미가 정해지지 않은 scan fixture는 가짜 기준선이 된다. | 두 텍스트 기준선만 유지하고 실제 계약 확정 뒤 독립 평가를 만든다. |

## 결과

- `.txt`만 허용하고 모든 수집 문서는 `source_kind=text`로 유지한다.
- 기존 두 레이아웃 평가, 기본 CI, Render 읽기 전용 데모의 동작은 변경하지 않는다.
- OCR은 "미구현"이 아니라 **현재 릴리스에서 의도적으로 채택하지 않은 확장**이다.

## 재개 조건

[P-001 OCR Gate 결정 패킷](../decisions/p001-ocr-gate.md)의 실제 스캔 요구와 모든 기술·보존
선택값이 확정될 때만 이 결정을 대체한다.
