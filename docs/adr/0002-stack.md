# ADR 0002 — FastAPI + SQLite + 서버 렌더링 UI

- 상태: 채택
- 날짜: 2026-11-26

## 배경

포트폴리오 데모는 무료 호스팅에서도 1명이 60초 안에 전체 흐름을 확인할 수 있어야 한다.
개발 환경에는 Node.js가 없고, 별도 프런트엔드 빌드 파이프라인은 유지비만 늘린다.

## 결정

1. API와 화면을 FastAPI 하나로 제공한다.
2. 화면은 Jinja2 서버 렌더링 + 최소 CSS/JS로 만든다. SPA·번들러·npm을 쓰지 않는다.
3. 데이터는 SQLite 단일 파일. Docker에서는 볼륨에 둔다.
4. 감사 이벤트는 애플리케이션 코드와 DB 트리거 양쪽에서 append-only를 강제한다.

## 결과

- 장점: 한 프로세스, 한 언어, 한 배포 단위. CI가 `pip install` + `pytest`로 끝난다.
  60초 데모에서 API와 화면이 같은 상태를 보여 준다.
- 단점: 다중 사용자 동시성·멀티테넌시에 약하다. 이는 명시적 비목표다.
- 재검토 조건: 실제 사용자 인증·동시 편집이 요구되면 Postgres + 세션 인증으로 분리한다.

## 보안 경계

- 업로드 크기 제한을 Content-Length와 스트림 바이트 양쪽에서 강제한다.
- CSP, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`를 기본 헤더로 둔다.
- 업로드 원문은 HTML로 렌더링하지 않고 항상 이스케이프한다(Jinja2 기본 자동 이스케이프).
