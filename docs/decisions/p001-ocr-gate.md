# P-001 OCR Gate 결정 패킷

상태: **결정 완료 — 현재 릴리스 미도입(텍스트 전용 유지)**
작성일: 2026-11-27  
적용 범위: 현재 릴리스에서 OCR을 채택하지 않는 P-001 결정 기록. 이 문서는 OCR 기능,
이미지/PDF 업로드, 외부 API, OCR 바이너리 또는 데이터 보존을 승인하지 않는다.

## 왜 이 Gate가 필요한가

현재 제품은 합성 `.txt`만 받고 `source_kind=text`로 처리한다. 스캔 입력을 받기 시작하면
입력 형식, 엔진 라이선스, 원본의 외부 전송과 보존, 신뢰도 산정이 모두 사용자에게 영향을 준다.
이 값을 정하지 않은 채 `source_kind=scan`·가짜 OCR 결과·이미지 확장자를 코드에 넣으면
작동하는 기능처럼 보이지만 실제 책임 경계가 없다.

## 오너가 확정할 입력

현재 릴리스의 선택값은 "필요 없음"이다. 향후 실제 스캔 요구가 생겨 Phase 16을 재개하려면,
아래 표의 모든 `미결정`을 선택값으로 바꾼 뒤에만 시작한다.

| 결정 항목 | 선택값 | 허용 예시 | 구현에 미치는 영향 |
|---|---|---|---|
| 실제 요구 | 필요 없음(현재 릴리스) | 스캔 영수증, 송장 PDF, 둘 다, 필요 없음 | 현 텍스트 경로 유지 |
| 허용 입력 형식 | 미결정 | PNG/JPEG, 이미지 PDF, 둘 다 | MIME/크기/페이지 수 검증과 fixture 설계 |
| OCR 엔진·라이선스 | 미결정 | 로컬 OSS 엔진과 버전, 승인된 SaaS와 계약 | 의존성·재현성·라이선스 고지 |
| 실행 위치·전송 | 미결정 | 로컬/Docker만, 승인된 외부 API | 네트워크 정책·비밀값·배포 경계 |
| 최소 품질 임계값 | 미결정 | 필드 confidence 0.90 이상 | 미달 시 자동 `HOLD` 기준 |
| 근거 형식 | 미결정 | 텍스트 span + 좌표, 둘 다 필수 | span/좌표 미확보 시 자동 `HOLD` |
| 원본 보존·삭제 | 미결정 | 저장 안 함, N일 보존, 법적 보존 | 저장소·삭제 작업·접근 통제 |
| 실패 처리 | 고정 | 엔진 오류·저신뢰·근거 없음은 `HOLD` | 자동 승인·결정론 fallback 금지 |

## 고정 안전 계약

1. OCR 결과는 기존 텍스트 평가와 섞지 않는다. `source_kind=scan` 전용 합성 36건 이상,
   독립 지표와 별도 CI job을 사용한다.
2. confidence가 임계값 미만이거나, 인용 가능한 evidence span/필요 좌표가 없으면 blocking
   `HOLD`다. 사람 승인 전 자동 통과시키지 않는다.
3. 기본 CI에는 비밀값·네트워크·외부 OCR 바이너리를 넣지 않는다. 필요 시 전용 환경에서
   격리하고, 오프라인 계약 테스트는 계속 통과해야 한다.
4. 현재 `.txt` 업로드, `source_kind=text`, 두 텍스트 레이아웃 기준선과 읽기 전용 Render
   데모는 Phase 16 전까지 바꾸지 않는다.

## 결정 후 Phase 16의 최소 완료 기준

- 확정한 엔진 경계를 가진 scan 전용 입력 어댑터
- 합성 scan 36건 이상과 기대 결과·manifest·실패 사례
- field/document 일치, `HOLD` 재현율·오보류율, evidence/좌표 유효성의 독립 리포트
- 낮은 품질·span/좌표 누락·provider 오류가 승인으로 새지 않는 테스트
- 기존 두 텍스트 평가 기준선과 공개 읽기 전용 경로의 회귀 테스트
