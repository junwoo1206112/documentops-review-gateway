# Phase 15 — 두 번째 텍스트 레이아웃

- 상태: 완료 (2026-11-26)
- 범위: 합성 텍스트 문서의 파이프 품목 표 레이아웃. OCR·LLM·인증·실제 문서는 포함하지 않는다.

## 확정 명세

`작성일:`과 정확한 `품목 | 수량 | 단가 | 금액` 헤더를 함께 요구한다. 품목 행은 비어 있지 않은
4개 셀을 `|`로 구분한다. 기존 공백 표/`작성일자:`와 혼합, 표식·열 누락, 중복 헤더는 422로
거절한다. 값 누락 라벨은 유지해 기존 검증 규칙이 HOLD를 판정한다.

## A/B/C 교차 검증

| 관점 | 발견 | 반영 |
|---|---|---|
| A. 제품 | 두 양식을 느슨하게 허용하면 지원 경계를 설명할 수 없다. | 명시적 표식과 상호 배타적 detector를 도입했다. |
| B. 보안/운영 | 새 입력 경로가 기존 업로드 제한·근거 검증을 우회하면 안 된다. | 동일 `.txt` ingestion, span 검증, 규칙·공개 읽기 전용 경로를 재사용했다. |
| C. QA/평가 | 기존 36건에 새 레이아웃을 섞으면 회귀 원인이 흐려진다. | `fixtures/evaluation_layout2`에 독립 36건·정답·manifest를 생성하고 별도 평가했다. |
