## 시작 방법 (Windows Narrator)

1. `scripts/run_local.cmd`를 더블클릭하고 서버 창을 열어 둔다.
2. 브라우저에서 `http://127.0.0.1:8000`을 연다.
3. `Win + Ctrl + Enter`로 Narrator를 켠다. 키보드만 사용한다.
4. 아래 체크리스트를 순서대로 수행한다. 발견 내용은 **실제로 들은 문구**로 적는다.
