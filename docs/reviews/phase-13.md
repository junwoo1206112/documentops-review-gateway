- 상태: **완료 (2026-11-26)**
- 자동 DOM/대비/반응형 점검은 Phase 11에서 완료됐으나, 이 문서는 실제 스크린리더 청취로만 완료한다.
- 데이터: 로컬 합성 fixture `fixtures/demo/DEMO-0001.txt`, `DEMO-0002.txt`

## 시작 방법 (Windows Narrator)

1. `scripts/run_phase13_screenreader.cmd`를 더블클릭하고 서버 창을 열어 둔다.
   이 실행 파일은 매번 새 SQLite DB와 포트 `8001`을 사용하므로, 이전 데모 업로드 때문에
   정상 문서가 중복 HOLD가 되는 일을 막는다.
2. 브라우저에서 `http://127.0.0.1:8001`을 연다.
3. `Win + Ctrl + Enter`로 Narrator를 켠다. 키보드만 사용한다.
4. 아래 체크리스트를 순서대로 수행한다. 발견 내용은 **실제로 들은 문구**로 적는다.
